1. פוגאצ'אר חושף את יעדיו ל-2027: טור דה פראנס, אליפות עולם ו-וואלטה

טאדיי פוגאצ'אר, אחד הרוכבים הגדולים בעולם, אישר את מטרותיו העיקריות לעונת 2027. לאחר עונה מוצלחת שנקטעה עקב פציעה בוואלטה, הרוכב הסלובני יתמקד בניסיון לזכות בטור דה פראנס, באליפות העולם ובמירוץ הוואלטה אספניה. זו תהיה הפעם הראשונה שפוגאצ'אר מציב את הוואלטה כיעד מרכזי, מה שמרמז על שאיפה להשלים את כל שלושת הגראנד טורים. הוא גם הבהיר את נסיבות התאונה שסיימה את עונתו, ודחה "פייק ניוז" בנושא.

2. טאו גייגן הארט מצטרף ל-EF Education-EasyPost בחיפוש אחר שיא חדש

טאו גייגן הארט, זוכה ג'ירו ד'איטליה לשנת 2020, חתם בקבוצת EF Education-EasyPost לקראת עונת 2027. הרוכב הבריטי עוזב את לידל-טרק לאחר שלוש עונות שכללו התמודדות עם פציעות ובעיות בריאות. גייגן הארט הביע תקווה שהמעבר לקבוצה האמריקאית יאפשר לו למצוא מחדש את הכושר שאפיין אותו בשנותיו הטובות ביותר. המהלך מסמן פרק חדש בקריירה של אחד הרוכבים המוכשרים בדבוקה, ומעורר ציפייה לראות את יכולותיו במדי קבוצתו החדשה.

🔗 Cyclingnews

3. שתי קבוצות וורלדטור, כולל Picnic-PostNL, החמיצו את מועד הרישום ל-2027

דרמה בעולם האופניים המקצועני: קבוצות הוורלדטור Picnic-PostNL ו-Jayco-AlUla החמיצו את מועד ההגשה הראשוני של המסמכים לרישום לעונת 2027. מחדל זה, הנוגע הן לקבוצות הגברים והן לנשים, מעורר חששות לגבי עתידן של הקבוצות והשלכותיו על חוזי הרוכבים. ה-UCI אישר כי רוכבים עשויים להיות רשאים לסיים את חוזיהם במקרה של אי-רישום. המצב מדגיש את האתגרים הפיננסיים והלוגיסטיים העומדים בפני קבוצות הצמרת, וצפוי להשפיע על שוק ההעברות.

4. קיגן סוונסון וסופיה גומז ויאפאניה זוכים בתארי ה-Life Time Grand Prix

עונת הגראבל של ה-Life Time Grand Prix הגיעה לסיומה עם זכיות מרשימות של קיגן סוונסון וסופיה גומז ויאפאניה, שכל אחד מהם קטף את התואר בפעם הרביעית. סוונסון נאלץ להילחם קשה במיוחד כדי להבטיח את תואר הגברים, בעוד גומז ויאפאניה הוכיחה שוב את עליונותה הבלתי מעורערת בקטגוריית הנשים. התחרות האינטנסיבית וההופעות העקביות של שני האלופים מדגישות את מעמדם בצמרת עולם הגראבל, ומבססות את שמם ככוכבי הסדרה.

5. רונן אוז'ה סובל משיתוק פנים חלקי לאחר תאונה קשה

רוכב האופניים הצרפתי הצעיר, רונן אוז'ה, סובל משיתוק פנים חלקי וממספר שברים בעקבות תאונה קשה בטור דה לאנגקאווי. למרות הפציעות הקשות, אוז'ה נשאר במצב רוח טוב ואף התבדח על כך ש"קריירה חדשה כפרצופאי מקצועי מחכה לו". הוא עדיין מאושפז בבית חולים במלזיה, כשבועיים וחצי לאחר התאונה. אנו מאחלים לו החלמה מהירה ומלאה ושובו למסלולים בהקדם האפשרי.
