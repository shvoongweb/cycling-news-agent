1. סייקס הצעיר כובש את ג'ירו די לומברדיה

פול סייקס הצרפתי רשם היסטוריה מרגשת כשזכה במרוץ המונומנט הקלאסי ג'ירו די לומברדיה, והפך לרוכב הצעיר ביותר אי פעם שזוכה בתואר יוקרתי זה. סייקס בן ה-20 ביצע מהלך סולו מבריק שהותיר את מתחריו מאחור, והוכיח את הפוטנציאל העצום הטמון בו. ניצחון זה מציין את הצלחתו הראשונה במונומנט ומסמן את עלייתו כאחד הכוכבים העולים בעולם האופניים.

2. מחאת רוכבים חסרת תקדים: עיכוב הזינוק לג'ירו די לומברדיה בדרישה לבטיחות

רוכבי הפלוטון ביצעו מחאה נדירה וחסרת תקדים לפני זינוק מרוץ ג'ירו די לומברדיה, ועיכבו את התחרות בחמש דקות. המחאה הגיעה כתגובה לחששות גוברים לגבי בטיחות הרוכבים, עם דרישה ברורה מה-UCI ומארגני המרוצים לנקוט בצעדים משמעותיים יותר. רוכבים בכירים כמו רמקו אבנפול הובילו את הקריאה לפעולה, תוך הדגשה כי 'אנשים מתים' וכי המצב אינו יכול להימשך.

3. מריאן ווס זוכה באליפות העולם בגראבל בפעם השנייה
