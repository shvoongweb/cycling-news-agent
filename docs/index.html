טור דה פראנס 2026: פוגאצ'אר חוגג ניצחון כללי, ואן דר פול מנצח את שלב הסיום

הטור דה פראנס 2026 הגיע לסיומו המרגש, כאשר טאדיי פוגאצ'אר מ-UAE Team Emirates XRG הבטיח את ניצחונו המוחץ בדירוג הכללי, והוכתר כאלוף הטור בפעם החמישית. פוגאצ'אר הציג דומיננטיות לאורך כל המרוץ, והותיר את מתחריו מאחור בפער משמעותי.

השלב האחרון, שלב 21, הסתיים כמצופה בספרינט מהיר ודרמטי בשאנז אליזה בפריז. מת'יו ואן דר פול מ-Alpecin-Deceuninck היה המהיר מכולם וזכה בניצחון יוקרתי, כשהוא מקדים בקו הסיום את יספר פיליפסן ומאדס פדרסן, שסיימו באותו זמן.
