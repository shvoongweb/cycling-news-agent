1. פרימוז' רוגליץ' חותם ב-NSN: פרק חדש בקריירה

סאגת ההעברות של פרימוז' רוגליץ' הגיעה לסיומה: הרוכב הסלובני האגדי חתם על חוזה לשנה אחת בקבוצת NSN. לאחר שלוש שנים מוצלחות במדי Red Bull-Bora-Hansgrohe, רוגליץ' מחפש אתגרים חדשים ו"פרק אחרון" בקריירה המפוארת שלו. המעבר מבטיח עונה מרתקת עם אחד מרוכבי הגראנד טורס המובילים בעולם, שעדיין מאמין שיש לו עבודה לעשות. אוהדי הרכיבה מצפים בכיליון עיניים לראות את השפעתו על הקבוצה החדשה.

3. עידן חדש ל"מגליה רוזה": MAAP תייצר את חולצת המוביל בג'ירו ד'איטליה

4. סוף לשיתוף הפעולה: TotalEnergies עוזבת את Netcompany-Ineos
